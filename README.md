# .github

Organization-level community files for [OKForest](https://github.com/okforest).

- `profile/README.md` renders on [github.com/okforest](https://github.com/okforest).
- `SECURITY.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, the issue templates
  in `ISSUE_TEMPLATE/`, and `pull_request_template.md` apply to every repository
  in the organization that does not have its own.
- `TRADEMARKS.md` summarizes the trademark policy for the OKForest name and
  logo; the full policy is at https://www.okforest.ai/trademarks/.
