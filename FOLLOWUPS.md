# Follow-ups

The planning doc for this repository; move items to GitHub Issues as the
project matures.

- **Email aliases before publishing.** `security@okforest.ai`,
  `conduct@okforest.ai`, and `trademarks@okforest.ai` are referenced here and
  must exist before the repository goes public.
- **Verify the profile logo after the first push.** `profile/README.md` uses
  relative image paths in a `<picture>` element; confirm both the light and
  dark logos render on github.com/okforest, and switch to absolute
  `raw.githubusercontent.com` URLs if they don't.
- **Profile toolkit table.** Once the CLI is on npm (and later the Validate
  Action and Skills), add a table like Elicitly's linking `okforest`,
  `@okforest/okf`, `@okforest/validate`, `okforest/validate`, and
  `okforest/skills`.
- **Organization settings.** Upload `github-avatar.png` from the brand assets
  as the organization picture, set the display name to "OKForest", and enable
  private vulnerability reporting on each public repository.
- **Trademark.** Run the USPTO search and register the OKForest wordmark
  (see the product brief); update `TRADEMARKS.md` with the registration once
  granted.
